EdgeClose Privacy Policy

Effective date: August 29, 2026

What EdgeClose does

EdgeClose closes website tabs that you configure after the selected period of inactivity. You can set a separate daily From and To session for each website, including overnight sessions such as 23:00 to 07:00. It processes browser tab URLs only to determine whether a tab matches one of your configured website patterns.

Data stored

EdgeClose stores website patterns, timeout settings, warning settings, schedule times, sound preferences, and temporary per-tab activity timestamps in Microsoft Edge extension storage on your device. It also stores a temporary pause state and a bounded local audit log containing EdgeClose management events. The audit log intentionally excludes passwords, password hashes, salts, browsing URLs, page titles, rule patterns, tokens, and secrets.

The settings password is never stored in plaintext. EdgeClose stores a randomly salted PBKDF2/SHA-256 password verifier and its iteration count locally. Passwords are not transmitted to the developer, GitHub, analytics services, or websites.

Persistent audit copy

EdgeClose also maintains a sanitized audit-log copy in the browser's Downloads folder at EdgeClose/audit-log.json. This is a normal user file and is independent of the extension's storage, so an existing copy remains on the computer if the extension is later removed. The extension cannot record a new uninstall event after it has been removed.

Data shared

EdgeClose does not send browsing history, page contents, keystrokes, mouse actions, passwords, stored settings, or audit-log data to the developer or any analytics provider. The Options page may request public release metadata from the GitHub API to display available EdgeClose versions; no password, browsing URL, page content, or audit-log data is included in that request.

User interaction

Timer resets are based on trusted browser user-interaction events such as pointer, keyboard, wheel, touch, input, and change events. DOM changes, animations, network activity, media playback, and synthetic script-generated events do not reset the inactivity timer.

Managed devices

On organization-managed devices, an administrator may provide EdgeClose rules through Edge's managed extension policy. Managed policy rules take precedence over local user settings. The extension does not transmit managed-policy values to the developer.

Your controls

You control which websites are monitored, the timeout, warning period, daily session, and warning sound when the extension is not administrator-managed. The toolbar provides temporary protection pause controls. Removing configured websites stops future monitoring. The persistent audit file in Downloads can be deleted by the user at any time.

Contact

For privacy questions, use the support contact published with the EdgeClose listing.
