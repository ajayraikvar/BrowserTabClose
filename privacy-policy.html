EdgeClose Privacy Policy

Effective date: August 31, 2026

What EdgeClose does

EdgeClose closes website tabs that match rules you configure after the selected period of inactivity. It processes browser tab URLs only to determine whether a tab matches a configured rule. A tab opened from a matched website may inherit that website's rule even if the new tab's own address does not match, unless this is turned off in settings or by an administrator.

Data stored

EdgeClose stores website patterns, timeout settings, warning settings, schedule times, sound preferences, a preference for whether tabs opened from a matched website are also monitored, temporary per-tab activity timestamps, a temporary pause state, password-verification data, and a bounded local audit log on the device.

The settings password is never stored in plaintext. A random salt and PBKDF2/SHA-256 password verifier are stored locally. Passwords are not transmitted to the developer, analytics services, or websites.

Audit log

The audit log contains EdgeClose management events only, such as installation, update, settings changes, pause/resume actions, and tab-close events. It intentionally excludes passwords, password hashes, salts, browsing URLs, page titles, rule patterns, tokens, secrets, page content, and keystrokes. The audit log is kept in the extension's local storage and shown on the Options page; EdgeClose does not write it to a file or send it to a remote server.

Data shared

EdgeClose does not send browsing history, page contents, keystrokes, passwords, stored settings, or audit-log data to the developer or any analytics provider.

User interaction

Timer resets are based on trusted browser user-interaction events such as pointer, keyboard, wheel, touch, input, and change events. DOM changes, animations, network activity, media playback, and synthetic script-generated events do not reset the inactivity timer.

Managed devices

On organization-managed devices, an administrator may provide EdgeClose rules through Edge's managed extension policy. Managed policy rules take precedence over local user settings. The extension does not transmit managed-policy values to the developer.

Updates

When EdgeClose is installed from the Microsoft Edge Add-ons Store, Microsoft Edge controls extension updates. EdgeClose does not download replacement extension packages from a third-party update server.

Your controls

You control which websites are monitored, the timeout, warning period, schedule, warning sound, and whether tabs opened from a matched website are also monitored, when the extension is not administrator-managed. Temporary pause and resume are available only from the password-protected Options page, and each pause or resume action requires re-entering that password. Removing the extension removes its extension storage, including the audit log, according to Edge's extension behavior.

Export and import

The Options page can export your configured website rules to a JSON file that you save yourself, and can import rules from a previously exported file. Exported files contain only website patterns, timeout, warning, schedule, and sound settings, and the child-tab monitoring preference. They do not contain your settings password, password hash, salt, or audit log. Importing a file loads its rules into the Options page for you to review; nothing is applied until you click Save settings. Because the settings password is not included in an export, reinstalling the extension always requires setting a new password.

Contact
