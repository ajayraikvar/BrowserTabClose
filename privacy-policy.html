EdgeClose Privacy Policy

Effective date: August 29, 2026

What EdgeClose does

EdgeClose closes website tabs that match rules you configure after the selected period of inactivity. It processes browser tab URLs only to determine whether a tab matches a configured rule.

Data stored

EdgeClose stores website patterns, timeout settings, warning settings, schedule times, sound preferences, temporary per-tab activity timestamps, a temporary pause state, password-verification data, and a bounded local audit log on the device.

The settings password is never stored in plaintext. A random salt and PBKDF2/SHA-256 password verifier are stored locally. Passwords are not transmitted to the developer, GitHub, analytics services, or websites.

Encrypted backup

To help settings and audit history survive extension removal, EdgeClose can maintain encrypted backup files in the browser's Downloads folder:

EdgeClose/config-audit.enc
EdgeClose/recovery-key.enc

The configuration/audit file is encrypted with AES-GCM using a randomly generated data key. That data key is protected with an RSA public key. The corresponding RSA private recovery key is itself encrypted with a password-derived AES-GCM key and stored in a separate recovery file.

The backup files do not contain a plaintext password. Without the password and both backup files, the configuration and audit history cannot be restored by EdgeClose. These files are ordinary user files, so a person with permission to edit the Downloads folder can still delete, replace, or corrupt them.

Audit log

The audit log contains EdgeClose management events only. It intentionally excludes passwords, password hashes, salts, browsing URLs, page titles, rule patterns, tokens, secrets, page content, and keystrokes.

Data shared

EdgeClose does not send browsing history, page contents, keystrokes, passwords, stored settings, or audit-log data to the developer or any analytics provider. The Options page may request public release metadata from the GitHub API to display available EdgeClose versions; no password, browsing URL, page content, or audit-log data is included in that request.

User interaction

Timer resets are based on trusted browser user-interaction events such as pointer, keyboard, wheel, touch, input, and change events. DOM changes, animations, network activity, media playback, and synthetic script-generated events do not reset the inactivity timer.

Managed devices

On organization-managed devices, an administrator may provide EdgeClose rules through Edge's managed extension policy. Managed policy rules take precedence over local user settings. The extension does not transmit managed-policy values to the developer.

Your controls

You control which websites are monitored, the timeout, warning period, schedule, and warning sound when the extension is not administrator-managed. Temporary pause and resume are available only from the password-protected Options page. Removing the extension removes its extension storage according to Edge's extension behavior, but existing encrypted backup files in Downloads remain unless the user deletes them.

Contact
