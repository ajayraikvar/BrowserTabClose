EdgeClose Privacy Policy

Effective date: August 29, 2026

What EdgeClose does

EdgeClose closes website tabs that match rules you configure after the selected period of inactivity. It processes browser tab URLs only to determine whether a tab matches a configured rule.

Data stored

EdgeClose stores website patterns, timeout settings, warning settings, schedule times, sound preferences, temporary per-tab activity timestamps, a temporary pause state, password-verification data, and a bounded local audit log on the device.

The settings password is never stored in plaintext. A random salt and PBKDF2/SHA-256 password verifier are stored locally. Passwords are not transmitted to the developer, analytics services, or websites.

Audit log

The audit log contains EdgeClose management events only, such as installation, update, settings changes, pause/resume actions, and tab-close events. It intentionally excludes passwords, password hashes, salts, browsing URLs, page titles, rule patterns, tokens, secrets, page content, and keystrokes.

A sanitized copy of the audit log is maintained locally as Downloads/EdgeClose/audit-log.json. The file is created when EdgeClose first records its installation event and is automatically refreshed when new audit events are recorded. EdgeClose does not send audit-log data to a remote server.

Data shared

EdgeClose does not send browsing history, page contents, keystrokes, passwords, stored settings, or audit-log data to the developer or any analytics provider.

User interaction

Timer resets are based on trusted browser user-interaction events such as pointer, keyboard, wheel, touch, input, and change events. DOM changes, animations, network activity, media playback, and synthetic script-generated events do not reset the inactivity timer.

Managed devices

On organization-managed devices, an administrator may provide EdgeClose rules through Edge's managed extension policy. Managed policy rules take precedence over local user settings. The extension does not transmit managed-policy values to the developer.

Updates

When EdgeClose is installed from the Microsoft Edge Add-ons Store, Microsoft Edge controls extension updates. EdgeClose does not download replacement extension packages from a third-party update server.

Your controls

You control which websites are monitored, the timeout, warning period, schedule, and warning sound when the extension is not administrator-managed. Temporary pause and resume are available only from the password-protected Options page. Removing the extension removes its extension storage according to Edge's extension behavior. Existing audit files in Downloads remain unless the user deletes them.

Contact

For privacy questions, use the support contact published with the EdgeClose listing.
